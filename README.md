# compositor_zh_hans
Compositor is an open-source image editor by ex-Apple designer Robbie Tilton — lightweight, subscription-free, Photoshop-style workflow (layers, masks, blend modes, curves, levels). This is a third-party Simplified Chinese localization of the Windows port (by Revan67).
Chinese localization based on Compositor (MIT License, Copyright (c) Wonder Assembly LLC). Original: [https://github.com/robbietilton/Compositor](https://github.com/robbietilton/Compositor) ; Windows port: [https://github.com/Revan67/Compositor-Windows](https://github.com/Revan67/Compositor-Windows)
